# Day 82: Permissions, ACLs & Least Privilege Defense in Active Directory

## Overview
Continued the Active Directory learning track by exploring how object permissions and Access Control Lists (ACLs) define access rules, how least privilege reduces attack paths, and how to document concepts safely.

## Key Concepts Learned

### 1. Permissions & Access Control Lists (ACLs)
- **Objects & Permissions:** Active Directory objects (such as users, groups, and computers) have permissions that control what actions an account can perform.
- **Access Control Lists (ACLs):** Rule lists tied to an object that specify who has permission to read, modify, or manage it, making them important when evaluating attack paths or hardening access.

### 2. Least Privilege & Defensive Hardening
- **Least Privilege:** Giving accounts only the minimum permissions required limits damage if an account is ever compromised.
- **Clean Administration & Reviews:** Separating privileged admin habits and reviewing permissions periodically helps remove risky stepping stones.

## Key Takeaways
- Over-broad ACL permissions on directory objects can create unintended stepping stones across an environment.
- Least privilege and regular permission reviews help keep Active Directory environments secure.
